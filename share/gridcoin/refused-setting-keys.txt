# Setting names that are honoured only in gridcoinresearch.conf or on the
# command line. The settings file (gridcoinsettings.json) ignores them and
# changesettings refuses to store them.
#
# Grammar: blank lines and lines starting with '#' are ignored. Every other
# line is one pattern matching ^[a-z0-9_*-]+$. '*' matches any run of
# characters, including none; every other character matches itself. Matching
# is case-sensitive and against the whole name, written without the leading
# '-' and without a "<section>." prefix. The "no" negation prefix is not
# removed, so "noncruncher" is a name in its own right.
#
# This file is the one source for the core (compiled in by
# build-aux/cmake/refusedkeys2header.cmake) and for tools that read the
# installed copy.
